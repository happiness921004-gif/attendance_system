# 여성행복센터 교육프로그램 관리 시스템

여성행복센터 75개 교육 프로그램 스마트 출결, 수강생 관리, 주차(증) 관리 시스템입니다.

## 주요 기능
- 📊 **종합 현황판 (대시보드)**: 75개 강좌 실시간 검색 및 출결 지표 요약
- 📋 **15주/12주 기수종합 출석부**: 회차별 스마트 출결 매트릭스 및 출결률 집계
- 👥 **강좌 및 수강생 관리**: 1,193명 수강생 실시간 검색, 강좌별 명부, 신규 등록
- 🚗 **주차(증) 관리**: 2시간 무료 주차 신청 현황 실시간 조회, 엑셀 다운로드, 즉시 등록
- 🔐 **관리자 비밀번호 변경**: 안전한 마스터 비밀번호 설정 및 관리자 PIN 비상 로그인
- ⚡ **구글 스프레드시트 양방향 실시간 동기화**: Apps Script Web App API 기반 자동 연동
